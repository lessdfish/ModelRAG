# 1. Goal

G10 moves model computation out of Java while keeping orchestration, state, policy, storage, ACL, transactions and index lifecycle in Java.

```text
Client
  ↓
Java Control Plane
  ├── API / Auth / ACL
  ├── Document lifecycle
  ├── IndexBuild lifecycle
  ├── Retrieval / Evidence
  ├── Agent Runtime
  ├── Tool Gateway
  ├── Cache / retry / timeout / health policy
  │
  └── modelrag-inference-client
          │ HTTP
          ▼
Python AI Compute Plane
  ├── /v1/embeddings
  ├── /v1/rerank
  ├── /v1/documents/parse
  └── /v1/ocr
```

Core invariant:

```text
Java = orchestration + state + policy + persistence + security
Python = stateless model computation
```

Python must NOT own dataset ACL, DocumentVersion/IndexBuild state, AgentState/checkpoint, approval, business transactions, PostgreSQL writes, Elasticsearch writes, Redis business state, or object-storage credentials.

# 2. Current baseline

At the G9 base commit:

- `EmbeddingService` still combines Java-side cache/batching/token/health policy with direct Spring AI/Ollama inference.
- The accepted embedding profile is still `Qwen3-Embedding-0.6B`, dimensions = `1024`.
- `HttpReranker` still owns remote HTTP plus Java fallback logic.
- Structured ingestion already has `StructuredDocumentParser`, `ParsedDocument`, `ParsedNode`, `ParsedEdge`, `DocumentParseMetadata`.
- Current PDF parsing is PDFBox heuristic parsing with `layoutPreserved=false`; textless scans raise `OCR_REQUIRED`.

G10 separates transport/model compute from Java orchestration without changing retrieval semantics.

# 4. Shared AiServiceClient

`AiServiceClient` is the single low-level Java HTTP transport.

It owns:

```text
base URL
internal service auth
connect timeout
request timeout upper bound
response-size cap
bounded concurrency
request-id propagation
JSON encode/decode
multipart streaming
HTTP status mapping
safe metrics
```

It must NOT own embedding cache, rerank fallback, IndexBuild state, retrieval policy, document persistence, Agent policy or business retry state.

Suggested config:

```yaml
modelrag:
  inference:
    enabled: false
    base-url: http://127.0.0.1:18180
    auth-token: ${MODELRAG_AI_AUTH_TOKEN:}
    connect-timeout-ms: 500
    request-timeout-ms: 30000
    max-concurrent-requests: 32
    max-json-response-bytes: 16777216
```

Do not log document text, query text, candidate text, vectors, OCR text, raw file bytes or auth tokens.

## 6.6 Embedding HTTP contract

```http
POST /v1/embeddings
Content-Type: application/json
Authorization: Bearer ...
X-Request-Id: ...
```

Request:

```json
{
  "model": "Qwen3-Embedding-0.6B",
  "dimensions": 1024,
  "texts": [
    "员工年假制度",
    "请假审批流程"
  ]
}
```

Response:

```json
{
  "model": "Qwen3-Embedding-0.6B",
  "dimensions": 1024,
  "embeddings": [
    [0.01, 0.02],
    [0.03, 0.04]
  ]
}
```

Real vectors contain 1024 values.

Python rejects empty input, >32 inputs, blank text, unsupported profile/dimensions and oversized text.

Java validates again.

---

## 6.7 Embedding resilience

Embedding compute is idempotent.

Allow at most one bounded transport retry for connection reset / 429 / 502 / 503 / 504 when caller budget remains.

Never retry past deadline.

Never switch embedding profile.

---

## 7.5 Failure semantics

Rerank is not a persisted index artifact.

Remote failure must:

```text
remote reranker fails
  ↓
Java local heuristic/RRF fallback
  ↓
mark reranker degraded
  ↓
continue retrieval
```

Do not fail the entire QA request because reranker is unavailable.

---

## 7.6 Deadline propagation

Remote timeout must be:

```text
min(
  remaining caller budget,
  configured remote rerank timeout
)
```

Do not create a new 30-second timeout when search has only ~500 ms remaining.

## 8.6 Parser routing policy

Do not delete local parsers.

Recommended:

```text
MD/TXT
  -> Java local

DOCX
  -> LOCAL_FIRST by default

PDF
  -> when Document AI enabled:
       REMOTE_FIRST
       remote failure + extractable text -> local heuristic fallback
       scanned/textless + remote unavailable -> OCR_REQUIRED / parse failure
     otherwise:
       current Java PDF parser
```

Suggested config:

```yaml
modelrag:
  inference:
    document-ai:
      enabled: false
      pdf-mode: REMOTE_FIRST
      docx-mode: LOCAL_FIRST
      timeout-seconds: 120
```

Allowed modes:

```text
LOCAL_ONLY
LOCAL_FIRST
REMOTE_FIRST
REMOTE_ONLY
```

Routing must be deterministic, not LLM-driven.

# 14. Failure matrix

| Operation | Failure behavior |
|---|---|
| Embedding during new build | fail new build; keep old ACTIVE build |
| Query embedding | semantic channel degrades per existing retrieval policy; never use a different model |
| Reranker | local/RRF fallback + degraded marker |
| Document AI on text PDF | safe local heuristic fallback allowed |
| Document AI on scanned PDF | OCR_REQUIRED/parse failure if remote unavailable |
| OCR | bounded failure; no partial DB mutation |
| Python unavailable | Java control plane stays alive; affected compute paths follow above policies |

Remote compute must not execute inside long DB transactions.

# 一、ACL Evidence 必须和 Retrieval Benchmark 分离

当前已经有：
- `G112AclIntegrationTest`
- User A 可访问 Dataset A
- User A 访问 Dataset B 被拒绝

但当前 Readiness 仍然使用：
`benchmark.noAclLeakage()`

而新的 benchmark report 已经不再写 `correctness.noAclLeakage`。

这意味着真实 JSON report 读取后，`noAclLeakage` 会默认 false，Readiness 永远无法真正通过。

## 目标
新增独立 ACL 证据对象，例如：

```java
public record AclIsolationEvidence(
    String status,
    String gitCommit,
    String testName,
    String executedAt,
    String reason
) {
    boolean passed() { ... }
}
```

以及：

```java
public interface AclIsolationEvidenceReader {
    AclIsolationEvidence read();
}
```

建议使用 JSON artifact：

```text
target/gate-evidence/acl-isolation.json
```

示例：

```json
{
  "status": "PASSED",
  "gitCommit": "d535ebe...",
  "testName": "G112AclIntegrationTest",
  "executedAt": "2026-09-12T..."
}
```

Readiness Gate：

```text
noAclLeakage
=
aclEvidence.status == PASSED

aclEvidenceCommitMatches
=
aclEvidence.gitCommit == 当前待切流 commit
```

不要再从 Retrieval Benchmark JSON 中读取 ACL 字段。

不要用环境变量 boolean 代替。

# 二、Benchmark Report 必须绑定当前 commit

当前 `BenchmarkEvidence` 已经有：

```text
gitCommit
```

但是 `isVerifiedFull()` 和 `CutoverReadinessEvaluator` 没有验证：

```text
benchmark.gitCommit == 当前待切流代码 commit
```

因此旧 commit 的 full report 理论上可以被新代码误用。

## 修复
增加 Gate：

```text
benchmarkCommitMatches
```

必须满足：

```text
benchmark.gitCommit
==
EvaluationRunner 当前 baseCommit
```

并且两边均不能为：

```text
unknown
blank
```

如果 baseCommit=unknown：

```text
NOT_READY_FOR_G12
```

推荐修改 evaluator 签名，显式传入 expectedGitCommit。

# 三、Full Benchmark 必须验证服务端 Java 21

G11.2 已经加入：

```text
runtime.serverJavaVersion
runtime.runnerJavaVersion
```

这是正确的。

但当前 `JsonBenchmarkEvidenceReader` 只检查 `serverJavaVersion` 非空。

以下情况仍可能被接受：

```text
17.0.7
unavailable
unknown
```

## 修复
`BenchmarkEvidence` 增加：

```text
serverJavaVersion
```

Readiness 增加：

```text
serverJava21
```

必须严格解析 Java major version == 21。

以下全部失败：

```text
17.x
unknown
unavailable
blank
```

`benchmark.py` full 模式还要保证：
- 每个 workload 都返回 serverJavaVersion
- 所有请求返回的 serverJavaVersion 一致
- 若出现多个不同版本，直接 NOT RUN
- 不允许 COMPLETED + unavailable

`ES 搜到文本` 不等于 `Active Build 已被证明正确检索`。
